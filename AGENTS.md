# Agent entrypoint

Read [CLAUDE.md](CLAUDE.md) in full before working in this repository. It is the
shared repository guide for every coding agent; its filename does not limit its scope.
Follow its task-specific reading routes before editing the corresponding area.

The guide explicitly routes visible changes to the UI contract and terminal changes
to the terminal rules. Read those files even when your host does not discover
`.claude/skills` or `.claude/rules` automatically.

Keep repository rules in the shared guide and its linked documents. This entrypoint
only supplies discovery for agents that load `AGENTS.md`.
