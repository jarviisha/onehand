# Board step 4: columns defined in Settings — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person defines a board's columns in *Settings ▸ Projects ▸ Board*. Each column gets
a row with up, down, edit and remove controls, and *Add column…* opens a dialog for its name,
work, *Starts*, *Moves on* and *Limit*. A project with no board makes one by picking a workflow,
and a board is taken away by *Remove the board…*.

**Architecture:** The Board box follows the *Routed commands* peer.
- **Rows:** `settings/projects/board.rs` draws the column rows through `list_row`/`list_rows`.
- **Form state:** a `ColumnDraft` on `Shell` (`shell/board_columns.rs`) holds the dialog's fields, as `RouteDraft` does.
- **Dialog:** the form is `dialogs/column.rs`, built like `dialogs/route.rs`.
- **Changes:** every change goes through `BoardDrive`'s column commands from step 3, carried by `crate::board::carry`.
- **Ids:** a new column's id is minted in the carrier.
- **Core:** core gains only the name rule.

**Tech Stack:** Rust, GPUI and gpui-component through `crate::controls` and `onehand_ui`.

**Spec:** `docs/superpowers/specs/2026-11-27-board-columns.md`, *Step 4*; the proposal's *The interface* › *Defining the columns*.

## Global Constraints

- **The `ui` skill governs every visible change.** Before the step is finished, answer `.claude/skills/ui/checklist.md` if it exists, else the skill's *Finishing* path.
- **Controls:** buttons through `crate::controls::action`, menus through `menu_below`/`menu_item`, choices through `onehand_ui::choice_track`/`segment`, fields through `onehand_ui::field` and `text_input(..).tall()`. No hard-coded colour, radius or size.
- **Words:** sentence case, and a label that asks first ends on `…`. The words of the column rows, and the help line under the box's *Columns* field:
  - A person's column reads *A person*; a workflow column reads *Runs <workflow name>*, or *Runs <id> (gone)*.
  - After that come *starts on a press* when it does, *moves on by a person* when it does, and *holds N* when it has a limit, joined by ` · `.
  - The help line under *Columns* reads *Backlog comes first and Done last; issues move left to right*.
  - The dialog's titles are *Add a column to <project>* and *A column of <project>*. Its fields are *Name*, *Work* (*A person* / *A workflow*), *Workflow* (a menu), *Starts* (*When it enters* / *When Start is pressed*), *Moves on* (*By itself* / *A person moves it*) and *Limit* (empty for none). The buttons are *Cancel*, then *Add* or *Save*.
  - The rows' controls are *Move up* and *Move down* (icon buttons named so), *Edit*, and *Remove…* in the danger ink. *Remove…* refuses with *Move its N issues out first* while the column holds issues.
  - *Remove the board…* asks *Remove the board from <project>?*, as the current unbind does.
- **A project with no board** keeps the *Workflow* menu. Picking one makes a board of To do and one column running it (`BoardDrive::bind`). Once there is a board, the menu goes: its columns name their workflows.
- **Removing an empty column does not ask.** It is a definition, put back as easily. Removing the board asks.
- **Core stays GUI-free.** No file past 800 lines of code. No comment or string names a document.
- **Checks:** `cargo test --workspace --locked`, `make clippy CLIPPY_EXTRA="-- -D warnings"`, `make fmt`. No launching or screenshotting the app: the owner looks in `make dev`.

## Review Focus

1. **A column is saved with an empty name, a name used twice, a limit of 0 or one that is not a number, or a workflow that is gone or cannot run on a worktree.** Each is refused in the dialog, which stays with the reason above its footer. The tests are in Task 1 and Task 2.
2. **A column holding issues is edited from a workflow to a person while a task works there.** It is refused, saying why, and nothing changes. The test is in Task 2.
3. **A column is removed or moved while the dialog is open on it.** The save of the open form is refused, or it goes to the column by its id, never by its place. The test is in Task 2.
4. **Move up on the first column, Move down on the last:** they refuse, with no write. The test is in Task 2.
5. **The board's file cannot be read.** The box says why and offers no column controls. The test is in Task 3.

### Task 2: The column form on the shell

**Files:**
- Create: `crates/app/src/shell/board_columns.rs` and `crates/app/src/shell/board_columns/tests.rs`.
- Modify: `crates/app/src/shell.rs` (the `column_draft: Option<ColumnDraft>` field and `mod board_columns`).

**Interfaces:**
- Produces:
  - `pub(crate) struct ColumnDraft { root: PathBuf, label: String, editing: Option<String> /* column id */, name: Entity<InputState>, person: bool, workflow: Option<String>, starts: Starts, moves_on: MovesOn, limit: Entity<InputState>, error: Option<String> }`.
  - `Shell::open_column_form(root, editing: Option<String>, window, cx)`. It fills the form from the column with that id, or with the defaults, which are a person's column, `OnEntry` and `ByItself`, with no limit.
  - `Shell::set_column_work(person: bool, cx)`, `set_column_workflow(id: String, cx)`, `set_column_starts(Starts, cx)` and `set_column_moves_on(MovesOn, cx)`.
  - `Shell::cancel_column(cx)`.
  - `Shell::save_column(window, cx)`.
    - It reads the limit: empty is none; anything else must be a whole number of at least 1, else *Limit is a whole number of at least 1*.
    - It builds a `Column` whose id is `crate::board::column_id()` for a new column, kept when editing.
    - `valid` is `crate::control::template(id, cx)` then `board::usable`. *A person* has no workflow to check. *A workflow* with none picked is refused with *Pick the workflow it runs*.
    - It calls `add_column` (at the end) or `edit_column`, with `working = crate::task::is_working`.
    - On `Ok` it carries the effects and closes. On `Err` it keeps the form, holding the reason.
  - `Shell::move_board_column(root, id: String, toward, cx)` and `Shell::remove_board_column(root, id, cx)`.
  - `crate::board::column_id() -> String` in `crates/app/src/board.rs`: `format!("col-{}", onehand_core::task::new_id())`.

### Task 3: The dialog and the Board box

**Files:**
- Create: `crates/app/src/dialogs/column.rs`.
- Modify:
  - `crates/app/src/dialogs.rs`: export it.
  - `crates/app/src/shell/render.rs`: draw it while `column_draft` is set, beside the route form. Add it to the "a dialog is open" check at :384.
  - `crates/app/src/settings/projects/board.rs`: the Board box.
  - `crates/app/src/shell/board_settings.rs`: add `remove_board`, which asks, then `unbind`.

**The dialog** follows `dialogs/route.rs`:
- It sits at `form_width`, titled through `title_row`.
- *Name* is `text_input().tall()`.
- *Work* is a `choice_track` of two `segment`s. When it is *A workflow*, a *Workflow* menu follows, through `menu_below` + `onehand_ui::picker`. The menu lists the library's workflows, capped at `TEMPLATES_SHOWN` with *N more not shown*.
- *Starts* is a track, drawn with a workflow only. *Moves on* is a track. *Limit* is `text_input().tall()`.
- The error, in the danger ink, stands above the footer.
- The footer is `footer_row` with *Cancel* (quiet) and *Add* or *Save* (primary).
- Enter presses Save from *Name* or *Limit*; Esc cancels.

**The Board box:**
- **With no board:** the *Workflow* field, as now.
- **With a board:**
  - A *Columns* field, its hint the help line, then the column rows (`list_rows`), each `list_row(name, line)`. A row's trailing controls are *Move up* and *Move down* (`short_icon`, refusing at the ends), *Edit* (`short_icon`, `SquarePen`) and *Remove…*. Then *Add column…*.
  - Then *Team*, as now.
  - Then a *Remove the board…* button in the danger ink.
  - *Edit workflow* moves into each workflow column's row: a `short_icon` named *Edit workflow*, when that workflow is on offer.
- **A board that cannot be read** shows its reason and nothing else but *Remove the board…*.
- The rows are capped at `COLUMNS_SHOWN = 20`, with *N more not shown*.
